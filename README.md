# QuBlitz 2026: Submit your project

**Deadline: Sunday, November 22, 11:00 AM**

## How to submit

1. **Put your work in a GitHub repository** and make it public so the judges can open it.
   (Quantum Create teams with a non-code project can skip this and attach their files to the form instead.)
2. **[Open a submission](../../issues/new/choose)**, choose the challenge you are submitting for, and fill out the form. Only one person needs to do this per team.

You can keep pushing to your repository until 11:00 AM, and we will judge what is on your main branch at the deadline.
If you would like to make changes to your submission, such as your repository link, please edit the submission instead of opening a new one.

## What to include

For full details, please look at the submission checklist in each challenge brief PDF in the drive.

- **Quantum Circuit Golf:** Submit your GitHub repository containing `submission.py`, dependencies, run instructions, and the experimentation/results required by the main challenge description. Each team must provide a file named `submission.py` defining the following function: `def optimize(circuit, config)`. During presentations, you will have to demonstrate the optimizer and explain its transformations.
- **Quantum Minesweeper:** Each team must submit:
  - **Code repository:** A GitHub repository containing the source code, quantum circuits, and instructions needed to reproduce the project.
  - **Challenge results:** A summary of completed levels, including simulation results and evidence that the proposed error-correction procedures work.
  - **IQM implementation:** The circuit implemented on IQM quantum hardware, the corresponding experimental results, and a brief explanation of the observations.
- **Magic State Verification:** Each team must submit:
  - **GitHub repository:** the complete working implementation, dependencies, and run instructions.
  - **Results:** a concise notebook or report presenting experiments of the team’s choice and explaining what they demonstrate about the algorithm.
  - **Attribution:** references for any published methods, external code, or AI-generated work used in the submission.
- **Quantum Create:** For code-based projects, teams must submit an accessible GitHub repository containing their relevant project files. For non-code projects, equivalent accessible project files and supporting documentation will be accepted. Each team will present its project through a live demonstration followed by questions from the judges.

At 11:00 AM we will close submissions and save a copy of every project as it stood at the deadline. The judges will review your submission along with your live demonstration, using the criteria listed in the challenge PDF and with an emphasis on demonstrated understanding.
